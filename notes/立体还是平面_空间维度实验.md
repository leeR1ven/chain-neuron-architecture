## 一、实验怎么做的（干净对照）

| 项 | 设置 |
|---|---|
| 规模 | 三组各 **1000 个细胞** |
| 每个细胞的出边 | **6 条局部连接 + 2 条随机连接** |
| 输入 | 同一个输入体积（8×8×8 个感受器），同一个种子 |
| **唯一变量** | 细胞坐标是 **2D**（40×25 网格）还是 **3D**（10×10×10 立方）→ 决定"局部邻居"落在哪 |
| 第三组（对照） | **输入随机连到细胞**上（用来说明"结果里有多少只是因为接线是局部的"） |
| "物体" | 感受器点阵里半径 0.18 的一团 |
| 呈现方式 | **20 个物体**（10 个平面位置 × 2 个深度 z=0.20 / 0.80），每个单独跑 40 步（dt=0.01） |
| 读数 | 最终活跃细胞集合（阈值 0.05）两两之间的**重叠度**（越低=分得越开） |

三个测量：
- **different**：两个**不相干**的物体 → 越低越好（说明网能把它们分开）
- **shifted**：同一个物体**轻轻挪一点** → 越高越好（说明网不把平移当成新物体）
- **same column**：同一个 x、y，**只有深度不同** → 越低越好（说明网能区分深度）

## 二、原始数据（照抄日志）

```
wiring                    different    shifted  same column cells lit
input at random cells         0.306      0.792        0.343       243
flat sheet, 2D coordinates    0.041      0.852        0.290        88
solid block, 3D coordinates   0.081      0.869        0.084       116
```

| 指标 | 随机接线 | 平面（2D） | 立体（3D） | 谁更好 |
|---|---|---|---|---|
| 两个不相干物体（越低越好） | 0.306 | **0.041** | 0.081 | **平面更好** |
| 同一物体轻挪（越高越好） | 0.792 | 0.852 | **0.869** | 立体略好 |
| 同位置不同深度（越低越好） | 0.343 | 0.290 | **0.084** | **立体压倒性好（3.5 倍）** |
| 亮起的细胞数 | 243 | 88 | 116 | — |

论文原话（R15）：

> **"Depth is therefore carried by the solid sheet and by nothing else, and it is bought at the price
> of some separation between different objects (0.041 to 0.081). That trade is the honest result
> rather than a shape that is better in every way."**
>
> 译：**深度只有立体网能承载**，而它是用"不同物体之间的分离度变差一点（0.041 → 0.081）"换来的。
> 这是一个**取舍**，**不是哪种形状全面更好**。

README 也原样写了这个代价：*"平面网把两个不相关的物体分得更开一点（0.041 对 0.081）"*。

## 三、怎么理解这个结果

**立体网赢在"多保住了一个维度"。**
接线的规则是"输入根据**就近**接到细胞上"。2D 网找最近细胞时**只用了 x、y**，深度这个坐标被投影掉了 —— 同一位置上下两个物体落到**同一批细胞**上，所以怎么都分不开（0.290 基本等于没分开）。3D 网的"就近"用了 x、y、z 三个坐标，两个深度落到不同的、但相邻的细胞上，于是活跃集合几乎不重叠（0.084）。

**代价是真的**：立体网里"不同物体"的重叠从 0.041 涨到 0.081 —— 分离度下降了一倍（虽然绝对值都很低）。

**共同前提**：随机接线那组（0.306）说明，**"局部接线"本身就是最大的功臣**（0.306 → 0.041）；立体相对平面的收益，只在"接线是按空间就近建立"的前提下才成立。

## 四、两个必须说清的边界

1. **正式出厂的那个 148k 皮层模型并没有用三维坐标。** 书里第 17 卷把"就近"定义成**门牌号相邻**（地址相邻），并且把"用解剖学距离做'就近'、想画一张三维脑图"直接列为**常见坑**。所以"皮层是立体的"这条是 `engine_v2` 里 1000 细胞的**独立探针结论**，不是主模型的实现方式。
2. **它测的是"片子的几何形状 + 就近接线"，不是"单个神经元是立体的"**。结论不该被读成"三维神经元比二维神经元聪明"，而应该读成：
   > **如果你的单元带有某种空间/结构坐标，而连接按"就近"建立，那么坐标保住的维度越多，能区分的输入维度就越多；代价通常是"不同模式之间的分离度"会下降一点。**

---

## 五、对我们自己的模型意味着什么

- 如果我们希望模型区分**某一类输入维度**（深度、时间、音高、位置…），就要保证**那个维度在"就近接线"里没被投影掉**：要么把它作为坐标的一维，要么给它单独的通道。
- 反过来，"把所有东西压成一维地址（门牌号）"是最省的做法，但**压掉的那些维度就再也分不开了**——这正是 2D 网分不开深度的原因。
- 立体不是免费的好：**多一维 = 分离度下降的代价**。要按"我们到底需要区分什么"来决定给几维。
