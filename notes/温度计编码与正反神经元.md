## 一、温度计编码（thermometer code）

### 一句话
**强弱不用"亮多强"表示，用"亮几对"表示。** 一个连续量分成 N 对细胞，第 L 档 = **前 L 对的正细胞亮、后面全亮反细胞**，一共能表示 **N + 1 级**。

### 精确规则

| 项 | 规则 |
|---|---|
| 分档 | 一个量（一个通道 / 一个特征）分成 **N 对**细胞 |
| 量化 | `级数 L = round(值 × N)`，再裁到 `[0, N]` |
| 编码 | 第 j 对（j = 0…N−1）：`L > j` → **正**细胞亮；否则 → **反**细胞亮 |
| 解码 | 数一数有几个**正**细胞亮，就是第几档（不需要算术，数数就行） |
| 级数 | **N + 1** 级（0 ~ N） |
| 唯一参数 | **`对数` = N**；细胞总数 = `N × 2` |

伪代码（仓库里的实际写法）：

```python
级 = clip(round(值 * N), 0, N)
for j in range(N):
    正亮 = 级 > j
    信号[2*(起点+j)]     = 1.0 if 正亮 else 0.0   # 偶数下标 = 正
    信号[2*(起点+j) + 1] = 0.0 if 正亮 else 1.0   # 奇数下标 = 反
```

### 为什么用这种"傻"编码

| 好处 | 说明 |
|---|---|
| 读出不要算术 | 数数正的亮几个 = 第几档 |
| 抗错 | 一两个细胞错只差一档，不会"变天" |
| 不需要"谁最强"的仲裁 | 没有胜者通吃，也就没有平局问题 |
| **相邻档只差一个细胞** | 所以"慢慢变强"是**一格一格挪**，不是跳变（学习一次也只能挪一档） |
| 单调可验 | 强度从 0 扫到最大，正细胞亮的个数应该是 0 → 1 → 2 → … → N，不回头 |

### 仓库里的实际用法与数字

| 通道 | 配置 | 规模 |
|---|---|---|
| 视觉 | 1920×1080 画面 → 24×16 马赛克 × 3 通道 × **10 对** | 24×16×3×10 = **11520 对 / 23040 个神经元**，11 级（0~10） |
| 听觉 | 频谱压成 1500 根频带 × 10 对 | 每根频带 0~10 档响度 |
| 运动（发力） | 200 块肌肉 × 10 对 | 每块肌肉 0~10 共 11 级发力 |
| 触觉/足部（负载、障碍、打滑） | 每种 4 对 | 用同一套编码 |

### 关键细节

- **输入层的"正反"就是"这一档过没过"**：正 = "亮度已经超过第 j 档"，反 = "还没到第 j 档"。亮度 0 = 该通道所有反细胞亮；亮度满 = 所有正细胞亮；中间 = 交界位置。
- **权重按"对"给，不按神经元给**：同一对在上一层看到的偏移共用一份强度，正细胞取 `+`、反细胞取 `−`。这样"亮度过没过这一档"才是同一件事的两面，而不是两个随机数。（`感觉网_多层.py` 里的原话）
- **特征池不参与学习**：它属于前处理网络，是固定的编码层。

## 二、正反神经元（书里叫"相反神经元"）

### 一句话
**每一种感觉通道都发两遍：一个细胞说"到了"，紧挨着的另一个说"没到"。** 于是**"什么都没有"本身也是一个读数**，而不是"两个都不亮"。

### 为什么必须成对（门口的比喻）

门口只装一盏红灯："亮 = 有人"。那么**灯灭的时候你分不清**是"没人来"还是"灯坏了 / 线断了"。
再装一盏绿灯，永远和红灯相反：红灯亮 = 有人，绿灯亮 = 没人。**任何时刻总有一盏亮着**，你永远不会对着"全灭"发呆。

### 精确规则

| 项 | 规则 |
|---|---|
| 范围 | **每一种感觉通道**都要有（视觉、听觉、触觉、足部障碍/负载/打滑…），**连"什么都没有"也算一路** |
| 形式 | **一对**细胞：正 / 反 |
| 竞争 | 池子先把信号累加，然后判定 **`正信号 >= 反信号` → 正赢**（**平局算正**） |
| 结果 | **恰好亮一个**——要么正、要么反；**激活之后清空信号** |
| 伴生细胞（感觉通道） | **伴生 = 1 − 原值**，在**同一步**里驱动。所以**第一个不亮时，第二个一定亮** |
| 用户口径 | 一个管"屈"一个管"伸"；一个管"向左"一个管"向右"；外界没信号时，由**报"安静"**的那一只亮 |
| 唯一参数 | 也是 `对数`（特征池：细胞总数 = `对数 × 2`） |

实现（`感觉网_多层.py`，就是这几行）：

```python
def 更新所有对(self):
    正信号 = self.信号[0::2]      # 偶数下标 = 正神经元
    反信号 = self.信号[1::2]      # 奇数下标 = 反神经元
    正赢 = 正信号 >= 反信号        # 平局算正
    self.激活[0::2] = 正赢
    self.激活[1::2] = ~正赢
    self.信号[:] = 0.0            # 清空本轮信号
```

### 白拿的两个性质（不需要额外代码）

| 性质 | 怎么来的 |
|---|---|
| 每一对**一定**有一个亮 | 配对竞争决定的，不用写 `if` |
| 整个池子**恰好一半**细胞亮 | 同上，不需要额外"归一化"步骤 |

> 书里反复强调的设计手法：**把一条"必须成立的约束"变成结构的副产品，而不是一句 `if`。**

### 它**不做**什么（边界必须划清）

- **不是三路互相抑制**——就是一对，没有第三方。
- **没有别的功能**——不判断、不打分、不仲裁、不管"注意"。
- 书里的原话：**"不做别的。"**

### 实测数字（论文 R19）

| 条件 | 读数 |
|---|---|
| 黑屏（"没亮那一半"的伴生通道） | **0.96985** |
| 白屏 | 与黑屏**对调** |
| 安静的屋子（听觉伴生） | **0.98983** |
| 站着、什么都没碰到身体（触觉/障碍/打滑伴生） | **1.00000** |
| 四只脚负重（一只脚：负载 + 伴生） | **= 1.000**（四只脚最大误差 0.000） |

读法：接近 1.0 说明"没有"这个读数很干净；对子和 = 1 说明两个读数互补，正好把"有 / 无"分成两半。
题库里对应的四道题：`the_dark_room_is_not_silence`、`a_quiet_room_is_not_a_sound`、`nothing_touching_it_is_not_nothing`、`the_weight_pair_still_carries_the_weight`——出生动物在三个种子上四道全过。

### 代价（论文照实报）

| 项 | 数字 |
|---|---|
| 细胞 | **+165,938** |
| 突触 | **+165,888** |
| 拆开看 | 每个光感受细胞配一个伴生细胞（165,888 条突触）＋"没亮那一半"自己的汇总表 18 个细胞＋四种反射感觉各 4 个伴生（32 个） |
| 规模对比 | 带它 **750,075 细胞 / 1,978,219 突触**；不带 584,137 / 1,812,331 |
| 每步耗时 | **13.29 ms**（不带 11.19 ms） |

### **必须照实说的缺口**

书里原话大意：**目前还没有任何下游去读任何一对里的第二个细胞。**

- 没有一条边从"相反表"通向反射、联想或运动细胞；画面**暗的那一半停在自己的汇总表上**。
- 所以：**一张黑画面目前仍然到不了任何反射细胞**——这不等于"动物注意到了灯灭了"。
- 要补这个洞，需要**偏好暗的细胞**（就像视网膜同时有 ON 细胞和 OFF 细胞那样），书里说那是**独立的结构步骤**，这一版没做。

### 一个反面教材（很重要）

早先的版本试过**把一对的两个读数加成"一个数"再往上放**，结果：**黑帧会让整张输出表全黑**——因为每一对的"负"细胞全亮了，而它们上面**没有任何细胞偏好暗**，整层被压住。
**结论：一对就是两个读数，不要合成一个标量。**

## 三、两个概念其实是同一套手法

| | 特征的正/反一对 | 感觉通道的相反神经元 |
|---|---|---|
| 在哪 | 特征层（每个特征分 N 对） | 每一种感觉通道上（一对，或 N 对） |
| 一对表达什么 | "**有**这个特征" / "**没有**这个特征" | "**往这边**" / "**没往这边**"（含"什么都没有"） |
| 共同点 | **一个二值事实用一对细胞表示**；恰好一个亮；把约束做成结构 | 同左 |

顺带一条相关的规则（第 18 卷）：**神经网络里每一层都可能出特征神经元，不是只有输入层**——所以"中间层只是过渡、最后一层才是答案"是错的。

## 四、照抄到我们自己的模型时要注意的

1. **编码层是固定的，不参与学习**：温度计编码属于前处理，学习发生在它之后的连接上。
2. **权重按"对"给，正取 +、反取 −**：这是让"过没过这一档"成为一件事两面的关键。
3. **"没有"必须是一个读数**：任何通道都要有"报安静 / 报没碰 / 报黑"的那一只，否则下游分不清"真的没有"和"线断了"。
4. **绝对不要把一对合成一个标量**（会重现"黑帧全黑"那个坏法）。
5. **两个读数都要有下游可读**：仓库自己的缺口就在这——建好了却没被读。我们如果采纳，第一步就要把"负读数"的出口接上（偏好暗/偏好无的细胞）。
6. 代价要算清：这份配置里相反神经元占了约 28% 的细胞（165,938 / 584,137）——**这也是"每一路都要有'没有'"的价格**。
