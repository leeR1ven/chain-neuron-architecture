# 架构纲要：特征神经元＝字、中继链、链条式前额叶与运动区

> 口述规格记录（2026-10-11）。这份是新架构的骨架，后续以它为准。

---

## 一、特征神经元 = 可变大小的"字"

- **每一层的神经元都可能成为特征神经元**（仓库里的原话：不是只有输入层）。
- 一个"特征"**不是一个神经元**：可能是一大片区域、一小片，**甚至就是一个神经元**。
- 因此可以把特征神经元**当作文字网络里"代表文字的那个神经元"**来用：
  - 文字网络里：一个字 = 一个神经元；训练后字与字之间形成有向连接。
  - 新架构里：一个特征 = 一簇神经元（规模可变）；特征与特征之间建立关联连接。
- **关联连接不受距离限制**：可以跨位置、跨层、跨区（否则"看到红球"和"听到声音"永远连不起来）。
  → 距离规则只管**出生结构**，联想靠**学习**建立。

---

## 二、脑区之间：中继链（因为区与区离得远）

- 不同脑区在立体空间里**相距很远**，直接连不现实 → 这是**前额叶出现的理由**。
- 做法：**在立体网络中每隔一小段空间就放一个神经元**。
  - 它**接收附近很多神经元的信号**（加权汇总 → 过阈值就亮）；
  - 激活后，**朝前额叶方向**继续把信号传下去。
- 于是一段距离 = 一串这样的中继神经元 = **一条链**。

### 已确认的两个细节

| 项 | 决定 |
|---|---|
| 中继是几个神经元 | **就一个神经元**。不做温度计编码，不要成组。 |
| 在哪里撒点 | **按脑区实际形状撒点**（在该区真实三维范围里准均匀撒，间距是参数） |

### 由此推出的一点（请核对）

一个中继只有"亮 / 不亮"，所以**单条链的一个中继传的是一个二值事实**，不是标量大小。
"是什么特征"不是靠某一个中继携带的，而是靠：

- **哪些链同时亮**（大量并行链上的空间pattern），
- **什么时候亮**（同一串中继被依次点亮的时序pattern）。

也就是说，前额叶收到的是**一堆链端上的稀疏时空pattern** —— 这正好和"前额叶只是一条条链的汇聚端"对上，也符合"皮层把大量外界信号压缩成少量信号"这一条。

---

## 三、前额叶 = 一条条链的汇聚端，**不是传统神经网络**

- 前额叶不是"输入→隐藏→输出"那种稠密网络；
- 它只是**一条条从各个脑区把信号送到前额叶的神经链条**。
- 直接好处：**反向的那套（前额叶→运动）也特别简单**。
- 后期如果出现"神经元之间需要复杂互连"的需求，才会在那里长出真正的神经网络（见第五节）。

---

## 四、运动区：也是链，不是网络；力度用编码神经元；必须有抑制

- **运动区不存在传统神经网络**，它同样是**通往肌肉的神经链条**。
- **不需要相反（正反一对）神经元**；
- 只需要**编码神经元来代表不同的力度** → 就是**温度计编码**（0~N 级，亮几档＝多大力）。
- **运动区必须有抑制神经元**负责压住行动；
  否则运动区神经元会**一直输出运动**（一直动、停不下来）。

---

## 五、暂时不用的部分

- **海马体：先不用。**
- 运动区/前额叶的"复杂互连网络"：**后期再说**——等出现"神经元之间需要互相复杂链接"的需求时再长出来。

## 六、和已学机制的对应关系

| 新架构的部件 | 用到的已有机制 | 出处 |
|---|---|---|
| 特征神经元（可变大小） | "每一层都可能出特征神经元"；**每个特征至少一对细胞**（正/反，恰好亮一个） | born-wired 第 6/18/21 卷 |
| 运动区力度编码 | **温度计编码**：一个量分 N 档，亮几档＝第几级，共 N+1 级 | born-wired 第 6/18 卷 |
| 运动区抑制 | 网里**没有负权重**，抑制是**另一群细胞** | born-wired 第 17 卷 |
| 中继链的出生连线 | **只能从"更靠近自己"的神经元里随机连**（软偏好，不是硬性只连最近） | 本对话 + codex 会话 + Ercsey-Ravasz 2013 / Perin 2011 |
| 特征之间的关联 | **时序赫布**：先亮的 → 后亮的加强；同时亮的互相加强；增量无上限但软饱和 | 文字网络（已实测） |
| 整体阈值调控 | 神经元阈值**不固定**，按"保持一定数量的字被激活"整体上下调 | 文字网络（已实测） |
| 权重增长 | **无上限、凹形增长 + 长尾回落**（少见快涨、常见难涨、超常见回落） | 文字网络（已实测） |

## 七、三个决定（已确认）

### 1. 中继就是**一个神经元**，不做温度计编码
一段距离上的中继 = 单个细胞：**加权汇总附近很多神经元的信号 → 过阈值就亮 → 朝前额叶方向继续传**。
（温度计编码只用在**运动区的力度**上，不用于中继。）

### 2. 中继**按脑区实际形状撒点**
在该区真实三维范围里准均匀撒点，间距是参数；不在整个立体空间里均匀撒，以免中继落在没有神经元的地方。

### 3. 运动区的抑制**两条都要**
- **前额叶并行的"别动"链**：发出动作的同时，另一条链驱动抑制细胞，把行动压住；
- **感觉区直接反射抑制链**：比如撞到东西/疼痛，直接压住运动输出，不经过前额叶。

---

## 八、待办（按依赖顺序）

1. 先做**最小闭环**：一个感觉区（例如视觉）→ 中继链 → 前额叶链条 → 运动链条（温度计力度）→ 肌肉；先不做海马、不做区内复杂网络、先不做"别动"链；
2. 用"就近随机"生成出生连线，跑通"信号能一路传到肌肉"；
3. 打开时序赫布学习，看前额叶链条上能不能长出"特征→行动"的关联；
4. 再加运动抑制（先加反射抑制链，再加前额叶并行"别动"链），验证"不会一直动"。
