# 链式神经元架构（chain neuron architecture）

> **定位**：本仓库是关联神经元架构的**链式部分**；目标是**架构自洽、可被其他部分替换/整合**，不是跑分。
> 整合前先看 [INTEGRATION.md](INTEGRATION.md)，跑 `python check.py` 和 `python test_architecture.py`；
> README 里的数字是冒烟测试，不是性能/泛化承诺。

立体神经元网络：各区各自成链、**每一层都往前额叶方向送**，前额叶是链的汇聚端，运动区是通往肌肉的链 + 力度分档。
出生连接固定（不可改变）；**链上每一级是专用线（一个中继只接一个上游神经元），只有前额叶做多输入汇聚**。
可塑连接规则已实现，默认关闭；结构可塑性（增/删神经元 + 常亮不送额叶）是可选项，见第四节。

---

## 一、规格

1. **分区**：视觉 / 听觉 / 触觉 / 平衡 + 前额叶 + 运动区。
2. **输入**：每个像素有具体位置，分 R/G/B 三个基础通道；每通道**温度计编码 N 档 + 正反一对**，每对恰好亮一个
   （纯黑时反细胞全亮——"什么都没有"也是一个读数）→ 输入层永远恰好一半活跃。
3. **立体与就近**：线段只连更靠近自己的（按 (y,z) 平面算，**层间 x 差不参与**，否则图像的"行"会被抹掉）。
4. **一层层往前送**：区内链是 **L1（ON/OFF 传感器）+ L2–L5** 共 5 层；**每一层都往前额叶送**；
   路上每隔一小段一级中继，**每个中继只接一个上游神经元（专用线，1:1）**；
   越靠近前额叶数量越多；前额叶神经元才把很多条线汇到一起（多输入 + 阈值 = 组合检测）。
5. **前额叶 = 汇聚端**（不是传统网络，内部暂不互连）。"汇聚"指一个前额叶神经元同时收很多条**专用线**，
   要其中足够多条同时活跃才过门槛——它检测的是"组合"，而每条线本身仍只传一个上游的细节。
6. **返回通路（往返链路）**：前额叶 → 返回中继 → **按位置送回原来那一层**（去程的反向）。
   第一级只看 6 条**随机铺开**的前额叶、第二级只看 4 条上一级 → 要前额叶一大片同时活跃才开；
   抑制细胞只压第一级，门槛可达（0.45×入边权重和）。**回程边 ≤ 前向一半，且不落回第 1 层**
   （第 1 层是外界直接驱动的传感器，落回去会锁死）。回程只是调制（每个层神经元只收 2 条），
   实测：前额叶亮 20% 打不开、50% 半开、90% 以上才开；撤掉输入 20 拍内退回，不会自转。
7. **运动区**：肌肉数 × 力度档数（不含抑制、不含中继）；亮的力度神经元越多、出力越大；有抑制神经元压住行动。
8. **门控**：不是"运动相关神经元亮了就发"——要看是不是**主要被激活的那批**；无关神经元经抑制细胞压住"往回发"的通路，
   只有大量运动相关神经元同时活跃才发得出去；去抑制由运动相关组自己打开。
9. **动态增删（可选）**：照立体网络最新规则，在**最后一层**加——链里的最后一层是**前额叶汇聚端**：
   取使用率 40–60% 的父单元，5% 父单元 → 每个拆 2 个子单元、各拿 2 条输入（2+2，总数 +10%）；
   从不激活、常亮/常灭的神经元删掉。
10. **常亮不送额叶**：输入层、第 1 层这类"永远一半亮"的神经元，跨输入几乎没有起伏，
    不带"是哪一个输入"的信息，就不往中继/前额叶送（按跨输入 std 筛，不按当前亮不亮）。

## 二、必须守住的规矩（每条都有实测依据）

| # | 规矩 | 依据 |
|---|---|---|
| 1 | 就近只看 (y,z)，层间 x 差不参与 | 否则每层只看到上一层最靠边一排 |
| 2 | **深层感受野 ≤ 上一层的 1/8** | 视觉第3层可分：约整层 0/12 → 1/4 时 2/12 → **1/8 时 12/12** |
| 3 | 不能窄到"只读一条通道"（取"主 + 对照"） | 那样第2层从 11/12 掉到 1/12 |
| 4 | 门槛/带宽按**该神经元自己拿到的信号**定 | 固定常数会在"整层死/整层饱和"之间来回跳 |
| 5 | **中继与前额叶那一层要更松**（门槛 ≈ 0.30×中位驱动） | 送达前额叶从 7/48 变 48/48 |
| 6 | 回程只当调制（边数 ≤ 前向一半） | 回程占到入边 22/30 时前向被压死；改版后实测 0.50/0.35 |
| 7 | 整体阈值调控只许微调（相对增益 ±0.05） | 放到 ±0.5 会顶到上限、门槛整体乘 1.5，深层必死 |
| 8 | 各层必须在分级区间 | 饱和传不出变化；死什么都没传 |
| 9 | 门槛不许有固定下限（如 0.02） | 它让下降链每过一级固定损失，力度低端被压缩 |
| 10 | **链上每级一对一（专用线），只有前额叶多输入汇聚** | 多级就近混合会把细节磨掉：随机输入相似性 ρ 从第2层 0.44 → 第4层 0.11 → 前额叶 0.0；改一对一后四区送额叶全部 100% |
| 11 | **增神经元：L2–L5 都能加，逐层试、按目标区选层** | 每加一个子单元同时加它的中继和 1 个前额叶接收端；中等规模 L2 0.566 / L3 0.543 / L4 0.532 / L5 **0.511**（越深越好） |
| 12 | **常亮/常灭不往前额叶送** | 输入层永远一半亮，但不带"是哪一个输入"的特征；按跨输入 std 判定 |
| 13 | **回程门槛必须可达（≤ 入边权重和）** | 原来写 2.0×权重和，act≤1 时永远打不开；改为 0.45×，抑制只压第一级；回程边从 4.7 倍前向降到 0.5 倍以内 |
| 14 | **回程要随机铺开地看前额叶，不能只取最近** | 只取最近会变成看局部小簇（20% 前额叶就打开）；随机铺开才是"一大片同时活跃" |
| 15 | **每层中继从本层 x 出发向额叶递进** | 原来从输入层 x 出发，L3/L4 会往身后的中继送（自检能抓到）；运动相关组取视觉最后一层额叶组 |
| 16 | **稳定 ID**：删除只改 alive、不移位；ids 允许含死编号 | 和立体网络 stable-ID 一致；消费方先按 alive 过滤，加神经元要补中继和额叶接收端 |

## 三、实测（10×10 像素、10 档、**5 层链** → 52,328 神经元 / 262,160 连接，可塑 0 条）

**每条通道各动最小一档**：

| 区 | 通道 | 第2层 | 第3层 | 第4层 | 第5层 | 送到前额叶 | 图案相似度 |
|---|---|---|---|---|---|---|---|
| 视觉 | 300（抽 30） | 30/30 | 30/30 | 30/30 | 30/30 | 29/30 | 0.02 |
| 听觉 | 20 | 20/20 | 20/20 | 20/20 | 20/20 | 20/20 | 0.10 |
| 触觉 | 40（抽 10） | 10/10 | 10/10 | 10/10 | 10/10 | 10/10 | −0.03 |
| 平衡 | 6 | 6/6 | 6/6 | 6/6 | 6/6 | 6/6 | 0.21 |

**判据**：网络确定无噪声——输入变一个神经元、后面跟着变，就是能区分。用"该层活动差 > 1e-4"，
**不用**"必须 > 0.1"（那是在要求变化大，会严重低估）。

**运动力度**（点亮前额叶运动相关组 → 出力档，满档 10）：

```
亮 1→0  亮 2→1  亮 3→3  亮 5→5  亮 7→8  亮 8→10  亮 10→10      （单调分级；亮 1 个时门控压着不出力）
```

**可塑连接**（默认关闭）：只有**刚变化**的神经元参与——`上一帧亮、这一帧灭` ↔ `这一帧刚亮`，以及同时刚亮的互相加强；
**一直亮着的（如输入层）和一直灭的一条边都不产生**。
增量 `Δw = η·a_i·a_j/(1+w/w_ref)^pow`：无上限、越涨越难涨、不归一化；"先亮的"那个神经元要用**上一帧**的活动
（它这一帧已灭、当前是 0）。每 200 拍可塑边整体降权 ×0.99 → 实测**常用 10.58 / 少用 0.56 / 从不用消失**。
新边可跨位置、跨层、跨区。

**训练循环**：随机出生参数 → 同一套固定题库打分 → 选优 → **精英保留 + 在最优者身上小步变异** → 再生成。
当前题库对微型模型（4×4、5 档）已经饱和：四组都是 1.000；机制已真正实现，要看出代际提升得换更难的题库。

## 四、结构可塑性（可选，`structure.py`）

不改链的走法，只改"链上有多少神经元、哪些信号继续往前额叶送"：

1. **加在哪（L2–L5 都能加）**：区内的链现在是 4 个中间层 **L2–L5**（L1 是 ON/OFF 传感器），
   候选层就是 L2/L3/L4/L5，逐层试：5% 父单元 → 每个拆 2 个子单元、各拿 2 条输入；
   子单元**局部重连下一层**，并各配专用线送前额叶；**每加一个子单元，就给这一层的前额叶组加 1 个接收神经元**
   （前额叶是落点，不是候选层，不跟 L2–L5 并列）。新接收端 `thr=0、soft=2×入边和`，原样收；
   **不要**把新线接到所有老前额叶神经元上（每个子单元接 3 条会把老神经元推到饱和）。
2. **减/筛：只对最新网络的区做**（默认 `gate_regions=("vision",)`）。听觉/触觉/平衡的专用网络还没做出来，
   现在用的是旧网络，参考输入下大量静默细胞；按"静默就删"会把它们连带打塌。这三个区**先只加不删**。
   减：删"跨输入平均 ≈ 0 / std ≈ 0"的神经元（含级联清理）；筛：只筛"平均 > 0.5、std ≈ 0"的常亮来源。
3. **任何结构改动后都不重标定整网**：只给新神经元/新接收端设门槛。实测整体重标会把增益洗掉
   （L3 0.192→0.178，重标后 0.203）；重标也会让某一层前额叶组塌掉（触觉 L4 0.47→0.86）。
   复测时按**每一层前额叶组**保护：目标区提升 >0.01、任何一组掉 >0.02 就回滚。

**逐层试（中等规模、触觉最差、同一批参考输入；用该区 L1–L5 额叶组拼起来的码）**：

| 加在哪 | 区内加了多少 | 该区相似度 |
|---|---|---|
| L2 | +10 | **0.582 → 0.559（选中）** |
| L3 | +12 | 0.573 |
| L4 | +16 | 0.581 |
| L5 | +20 | 0.582（新接收端还太弱，没变化） |

这一轮 L2 最好；L5 的接收端因为 L5 层本身活动低、信号弱，暂时没效果。**不是每层一样，要逐层试。**

**中等规模实测**（6×6 像素、5 层链 → 22,027 神经元 / 116,356 连接，`python structure.py`）：

| 步骤 | 结果 |
|---|---|
| 常亮筛选（只视觉） | 去掉 149 条进中继/额叶的边 |
| 减神经元（只视觉） | 删 45 个（静默 41、常亮/常灭 4），级联删 92 个 |
| 逐层试 | 触觉：L2 0.559、L3 0.573、L4 0.581、L5 0.582 → 选 L2 |
| 选中后 | 触觉 L2 +10（含中继/接收端）→ 全区组 **0.582 → 0.559**，保留 |
| 第二轮 | 触觉 L2 再加 10 → 全区组 0.559→0.505，但某一层组掉了，按保护回滚 |

四区（L1–L5 额叶组拼起来的码）：视觉 0.003→0.002、听觉 0.353→0.353、触觉 **0.582→0.559**、
平衡 0.353→0.353。网络 22,027→21,930 个神经元、116,356→115,361 条连接。

**完整规模实测**（10×10、5 层，52,328 神经元 / 448,240 连接，每区 5 条 + 随机 6 条）：
- 筛/删只做视觉：去 1,061 条边、删 242 个（级联 626）；听觉/触觉/平衡**结构不动、指标不动**；
- 触觉逐层试选中 L4：+26（含中继/接收端）→ 全区组 **0.326 → 0.314**，保留；
  L4 那一组 0.736→0.737（不动），margin 0.330→0.328；
- 结束：51,564 个神经元 / 438,313 条连接，**没有任何一层额叶组塌掉**。提升不大，但方向对、且不伤别的区。

**接线对照实验**（较早一轮，未含回程改动，只为对比接线方式）：

| 接线 | 前额叶对四区变化的相似度（视觉/听觉/触觉/平衡） | 随机输入相似性 ρ（第2层→第4层→额叶） | 连接 |
|---|---|---|---|
| 现在就近多输入（旧） | −0.11 / −0.07 / 无响应 / 无响应 | 0.44 → 0.11 → 0.00 | 496k |
| **专用线一对一（现默认）** | 0.00 / 0.07 / 0.13 / 0.04 | 0.44 → 0.11 → 0.02 | **362k** |
| 一对一 + 只取最近 k | 0.00 / 0.21 / 0.24 / 0.24 | 0.50 → 0.12 → −0.01 | 362k |
| 区内随机混线（无关信号） | 无响应 / 0.80 / 无响应 / −0.13 | 0.42 → 0.10 → 0.01（前额叶活动=0） | 496k |

结论：**把无关信号随机混进中继最差（前额叶直接不出响应）**；就近多输入次之，且逐级把细节磨掉；
**一对一专用线让四区都能送到前额叶，连接还少了 27%**。所以链上改成一対一；
区内 L2–L4 仍保留"就近多输入"（感受野 ≤ 1/8），因为区内确实要做局部组合，随机混才是灾难。
"只取最近 k"反而更差（感受野太像、多样性不够），所以仍保留在 3k 候选里随机挑的写法。

## 五、还没做到

1. **顺序学习、可塑连接接进主循环、开可塑后的实时性**：这三项由其他部分负责，本仓库不处理。
2. **实时性（静态）**：52,328 神经元 / 448,240 连接 → **8.08 毫秒/步**（20 毫秒一拍的 40%）。
3. **完整规模的结构可塑性只做了保守版**：筛/删只对视觉（最新网络）做，听觉/触觉/平衡结构不动；
   触觉加 L4 只把全区组从 0.326 拉到 0.314，提升不大。原因是旧区本身活动低、L5 接收端信号弱。
   下一步：等听觉/触觉/平衡的专用网络做出来，再把筛/删按区打开；L5 接收端要按该层实际活动量级定门槛。
4. **回程只是调制**：层神经元各收 2 条回程边，前额叶 90% 以上活跃才开，实测层活动最大只抬到 0.03；
   如果希望它真的能维持/回放一个模式，得再加强度或改成"调门槛"，本轮先守住"不自转"。

## 六、代码

```
code/
  brain.py        引擎：神经元/三位位置/就近连线/专用线 link/阈值带宽/整体阈值调控/删除神经元
  build.py        按规格搭建：输入编码、各区各层、专用线中继、前额叶汇聚、返回通路、门控、运动区；含 validate_spec
  calib.py        门槛带宽标定：按每个神经元自己拿到的信号定（浅→深，级联两遍）
  check.py        架构自检：ids/边/输入/每层→额叶/回程/门控/温度计（整合前必跑）
  structure.py    结构可塑性：增/删神经元、常亮不送额叶、前额叶相似度复测 + 回滚
  run.py          行为验收：颜色/位置区分、连通与延迟、门控、全部固定连接、实时性
  accept_all.py   总验收：四区逐通道表 + 运动力度表 + 可塑自测
  plastic2.py     可塑连接规则（实验性，未接进运行循环）
  test_architecture.py 架构不变量测试（规格校验/温度计/加删后自洽）
  test_plastic2.py  可塑规则自测（常用/少用/常亮不参与）
  test_force.py     运动力度分档自测
  test_structure.py 结构可塑性自测（专用线/常亮筛选/增删/回程门）
  train_loop.py     生成 → 固定题库 → 选优 → 精英保留 + 变异 → 再生成
INTEGRATION.md      给后续整合方的接口/契约/检查清单
docs/验收标准.md
```
