# 链式神经元架构（chain neuron architecture）

立体神经元网络：各区各自成链、**每一层都往前额叶方向送**，前额叶是链的汇聚端，运动区是通往肌肉的链 + 力度分档。
出生连接固定（不可改变）；**链上每一级是专用线（一个中继只接一个上游神经元），只有前额叶做多输入汇聚**。
可塑连接规则已实现，默认关闭；结构可塑性（增/删神经元 + 常亮不送额叶）是可选项，见第四节。

---

## 一、规格

1. **分区**：视觉 / 听觉 / 触觉 / 平衡 + 前额叶 + 运动区。
2. **输入**：每个像素有具体位置，分 R/G/B 三个基础通道；每通道**温度计编码 N 档 + 正反一对**，每对恰好亮一个
   （纯黑时反细胞全亮——"什么都没有"也是一个读数）→ 输入层永远恰好一半活跃。
3. **立体与就近**：线段只连更靠近自己的（按 (y,z) 平面算，**层间 x 差不参与**，否则图像的"行"会被抹掉）。
4. **一层层往前送**：**每一层都往前额叶送**；路上每隔一小段一级中继，**每个中继只接一个上游神经元（专用线，1:1）**；
   越靠近前额叶数量越多；前额叶神经元才把很多条线汇到一起（多输入 + 阈值 = 组合检测）。
5. **前额叶 = 汇聚端**（不是传统网络，内部暂不互连）。"汇聚"指一个前额叶神经元同时收很多条**专用线**，
   要其中足够多条同时活跃才过门槛——它检测的是"组合"，而每条线本身仍只传一个上游的细节。
6. **返回通路**：前额叶 → 返回中继 → **按位置送回原来那一层**（去程的反向）；要**很多前额叶神经元同时活跃**才打得开
   （抑制细胞 + 阈值一起构成门槛），否则 a→b→c→d→a 自己转个不停。**不能落回第 1 层**（那是外界直接驱动的传感器，落回去会锁死）。
7. **运动区**：肌肉数 × 力度档数（不含抑制、不含中继）；亮的力度神经元越多、出力越大；有抑制神经元压住行动。
8. **门控**：不是"运动相关神经元亮了就发"——要看是不是**主要被激活的那批**；无关神经元经抑制细胞压住"往回发"的通路，
   只有大量运动相关神经元同时活跃才发得出去；去抑制由运动相关组自己打开。
9. **动态增删（可选）**：中间使用频段（40–60%）的神经元旁边可以加新神经元（2 条最强输入 + 2 条随机输入，
   各配一根专用线送前额叶）；从不激活、常亮/常灭的神经元删掉。
10. **常亮不送额叶**：输入层、第 1 层这类"永远一半亮"的神经元，跨输入几乎没有起伏，
    不带"是哪一个输入"的信息，就不往中继/前额叶送（按跨输入 std 筛，不按当前亮不亮）。

## 二、必须守住的规矩（每条都有实测依据）

| # | 规矩 | 依据 |
|---|---|---|
| 1 | 就近只看 (y,z)，层间 x 差不参与 | 否则每层只看到上一层最靠边一排 |
| 2 | **深层感受野 ≤ 上一层的 1/8** | 视觉第3层可分：约整层 0/12 → 1/4 时 2/12 → **1/8 时 12/12** |
| 3 | 不能窄到"只读一条通道"（取"主 + 对照"） | 那样第2层从 11/12 掉到 1/12 |
| 4 | 门槛/带宽按**该神经元自己拿到的信号**定 | 固定常数会在"整层死/整层饱和"之间来回跳 |
| 5 | **中继与前额叶那一层要更松**（门槛 ≈ 0.30×中位驱动） | 送达前额叶从 7/48 变 48/48 |
| 6 | 回程只当调制（边数 ≤ 前向一半） | 回程占到入边 22/30 时前向被压死 |
| 7 | 整体阈值调控只许微调（相对增益 ±0.05） | 放到 ±0.5 会顶到上限、门槛整体乘 1.5，深层必死 |
| 8 | 各层必须在分级区间 | 饱和传不出变化；死什么都没传 |
| 9 | 门槛不许有固定下限（如 0.02） | 它让下降链每过一级固定损失，力度低端被压缩 |
| 10 | **链上每级一对一（专用线），只有前额叶多输入汇聚** | 多级就近混合会把细节磨掉：随机输入相似性 ρ 从第2层 0.44 → 第4层 0.11 → 前额叶 0.0；改一对一后四区送额叶全部 100% |
| 11 | **增神经元只加中间频段 + 少输入** | 高频分裂伤稀有信号；把无关信号随机混进中继最差（前额叶直接不出响应，PFC 活动距离 0） |
| 12 | **常亮/常灭不往前额叶送** | 输入层永远一半亮，但不带"是哪一个输入"的特征；按跨输入 std 判定 |
| 13 | **回程门槛必须可达（≤ 入边权重和）** | 原来写 2.0×权重和，act≤1 时永远打不开；改为 0.5×，且抑制只压第一级 |

## 三、实测（10×10 像素、10 档 → 42,510 神经元 / 532,894 连接，可塑 0 条）

**每条通道各动最小一档**：

| 区 | 通道 | 第2层 | 第3层 | 第4层 | 送到前额叶 | 图案相似度 |
|---|---|---|---|---|---|---|
| 视觉 | 300（抽 30） | 30/30 | 30/30 | 30/30 | 30/30 | 0.02 |
| 听觉 | 20 | 20/20 | 20/20 | 20/20 | 20/20 | 0.20 |
| 触觉 | 40（抽 10） | 10/10 | 10/10 | 10/10 | 10/10 | 0.06 |
| 平衡 | 6 | 6/6 | 6/6 | 6/6 | 6/6 | 0.20 |

**判据**：网络确定无噪声——输入变一个神经元、后面跟着变，就是能区分。用"该层活动差 > 1e-4"，
**不用**"必须 > 0.1"（那是在要求变化大，会严重低估）。

**运动力度**（点亮前额叶运动相关组 → 出力档，满档 10）：

```
亮 1→0  亮 2→2  亮 3→3  亮 5→7  亮 7→10  亮 8→10  亮 10→10      （单调分级；亮 1 个时门控压着不出力）
```

**可塑连接**（默认关闭）：只有**刚变化**的神经元参与——`上一帧亮、这一帧灭` ↔ `这一帧刚亮`，以及同时刚亮的互相加强；
**一直亮着的（如输入层）和一直灭的一条边都不产生**。
增量 `Δw = η·a_i·a_j/(1+w/w_ref)^pow`：无上限、越涨越难涨、不归一化；"先亮的"那个神经元要用**上一帧**的活动
（它这一帧已灭、当前是 0）。每 200 拍可塑边整体降权 ×0.99 → 实测**常用 10.58 / 少用 0.56 / 从不用消失**。
新边可跨位置、跨层、跨区。

**训练循环**：随机出生参数 → 同一套固定题库打分 → 选优 → **精英保留 + 在最优者身上小步变异** → 再生成。
当前题库对微型模型（4×4、5 档）已经饱和：四组都是 1.000；机制已真正实现，要看出代际提升得换更难的题库。

## 四、结构可塑性（可选，`structure.py`）

不改链的走法，只改"链上有多少神经元、哪些信号继续往前额叶送"：

1. **加**：只在中间频段（40–60% 使用率）的父神经元旁边加；新神经元只接 4 条输入
   （父神经元里 2 条最强的 + 2 条随机的），位置在同层 (y,z) 轻微抖动；
   **各配一根专用线**（1:1）接到这一层的中继，再送前额叶。
2. **减**：只删"跨输入平均 ≈ 0"（从不用）和"跨输入 std ≈ 0"（常亮/常灭）的神经元；
   删完把因此没有输入的 hop / 前额叶神经元级联删掉。
3. **常亮不送**：一批随机 + 变化参考输入，**只筛"平均 > 0.5、跨输入 std ≈ 0"的常亮来源**，
   把它进中继/前额叶的边去掉（常灭的走"减神经元"，不在这里砍；
   参考输入不足时把"只是没被这批输入碰到"的神经元当常灭删边，会把通路砍坏——完整规模上实测过）。
4. 每次结构改动后按每个神经元自己的入边/驱动重新标定门槛（步数要和初始标定一致，28 步会把深层的
   相似度带偏 0.05），复测四区相似度；**定点改动只看目标区变好、别区不显著变差，否则回滚**。

**中等规模实测**（6×6 像素 → 17,878 神经元 / 249,242 连接，`python structure.py`）：

| 步骤 | 结果 |
|---|---|
| 常亮筛选 | 去掉 170 条进中继/额叶的边（250 个常亮来源），不级联删神经元 |
| 减神经元 | 删 6 个常亮/常灭，级联删 12 个因此没输入的中继 |
| 加神经元 | 听觉 L4 +16（10%，另配 32 个专用线中继）→ 前额叶相似度 **0.305 → 0.287**，保留 |
| 再试 | 听觉 L4 再加 18 → 0.287 → 0.408，回滚 |

四区相似度（|余弦|，越低越分得开）：视觉 0.005→0.001、听觉 0.305→0.287、触觉 0.248→0.248、平衡 0.202→0.199。
网络 17,878→17,908 个神经元、249,242→249,859 条连接。听觉的"加神经元"把分辨率提上去了，其余三区没被带差；
再加一轮就过拟合式变差，回滚——说明"加多少"要按区、按当前分辨率停手。

**完整规模实测**（10×10，42,510 神经元 / 638,334 连接，每个区抽 5 条、随机 6 条）：
- 常亮筛选去掉 1,047 条边（1,111 个常亮来源），减神经元删 49 个（级联 98）→ 四区相似度基本不动
  （视觉 0.000 / 听觉 0.340→0.339 / 触觉 0.316→0.317 / 平衡 0.259→0.260），保留；
- 听觉 L4 加 26 个（10%）→ 0.339→0.369，变差，回滚。

也就是说：全尺寸下"筛常亮 + 减神经元"现在是安全的（不伤分辨），但"加神经元"还没找到
能在这个规模稳定提分辨的位置和规模；参考输入也只有 5 条/区，统计噪声大。
下一步：加大参考题库、按区回滚、并在更浅的层（L2/L3）试加，而不是只加 L4。

**接线对照实验**（同一中等规模、同一批输入）：

| 接线 | 前额叶对四区变化的相似度（视觉/听觉/触觉/平衡） | 随机输入相似性 ρ（第2层→第4层→额叶） | 连接 |
|---|---|---|---|
| 现在就近多输入（旧） | −0.11 / −0.07 / 无响应 / 无响应 | 0.44 → 0.11 → 0.00 | 496k |
| **专用线一对一（现默认）** | 0.00 / 0.07 / 0.13 / 0.04 | 0.44 → 0.11 → 0.02 | **362k** |
| 一对一 + 只取最近 k | 0.00 / 0.21 / 0.24 / 0.24 | 0.50 → 0.12 → −0.01 | 362k |
| 区内随机混线（无关信号） | 无响应 / 0.80 / 无响应 / −0.13 | 0.42 → 0.10 → 0.01（前额叶活动=0） | 496k |

结论：**把无关信号随机混进中继最差（前额叶直接不出响应）**；就近多输入次之，且逐级把细节磨掉；
**一对一专用线让四区都能送到前额叶，连接还少了 27%**。所以链上改成一対一；
区内 L2–L4 仍保留"就近多输入"（感受野 ≤ 1/8），因为区内确实要做局部组合，随机混才是灾难。
"只取最近 k"反而更差（感受野太像、多样性不够），所以仍保留在 3k 候选里随机挑的写法。

## 五、还没做到

1. **顺序学习**（看完连续画面后，只给第一帧能否自己往后演）：连接在长，但**没有出现**——
   已排除"连接太弱"（学习步长放大 12 倍、接触 150 遍，行为不变）；缺的是"当前状态退下去、由下一帧接管"的那一环。
2. **前额叶像文字网络那样"思考"**：可塑连接还没接进运行循环长期学习。
3. **实时性**：静态目标规模 42,510 神经元 / 638,334 连接 → **10.75 毫秒/步**（20 毫秒一拍的 54%）；
   可塑连接还没接进运行循环，开可塑后的步时会更高。
4. **完整规模的结构可塑性还不能真正增删**：参考输入不足（每区 3~5 条）时统计不可靠，
   全尺寸实测两处改动都自动回滚；要把参考题库加大、并把"按区回滚"做完，才敢在这个规模上动结构。

## 六、代码

```
code/
  brain.py        引擎：神经元/三位位置/就近连线/专用线 link/阈值带宽/整体阈值调控/删除神经元
  build.py        按规格搭建：输入编码、各区各层、专用线中继、前额叶汇聚、返回通路、门控、运动区
  calib.py        门槛带宽标定：按每个神经元自己拿到的信号定（浅→深，级联两遍）
  structure.py    结构可塑性：增/删神经元、常亮不送额叶、前额叶相似度复测 + 回滚
  run.py          行为验收：颜色/位置区分、连通与延迟、门控、全部固定连接、实时性
  accept_all.py   总验收：四区逐通道表 + 运动力度表 + 可塑自测
  plastic2.py     可塑连接规则（只有"刚变化"的神经元参与）
  test_plastic2.py  可塑规则自测（常用/少用/常亮不参与）
  test_force.py     运动力度分档自测
  test_structure.py 结构可塑性自测（专用线/常亮筛选/增删/回程门）
  train_loop.py     生成 → 固定题库 → 选优 → 精英保留 + 变异 → 再生成
docs/验收标准.md
```

```powershell
cd code
python accept_all.py     # 总验收（几分钟）
python test_force.py     # 运动力度
python test_plastic2.py  # 可塑规则
python test_structure.py # 结构可塑性（几秒）
python structure.py      # 结构可塑性演示（中等规模，几分钟）
python train_loop.py     # 训练循环
```
