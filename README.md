# 链式神经元架构（chain neuron architecture）

一套**立体（三维）神经元网络**：多个感觉区各自成链、**每一层都往前额叶方向送信号**，前额叶是"一条条链的汇聚端"，运动区是"通往肌肉的链 + 力度编码"。
所有连接在出生时就固定（**不可改变**），后天可塑连接的规则也已实现（默认关闭）。

> 这个库只包含**链式架构**这一部分（不含此前的文字网络）。

---

## 一、架构规格（按设计者的说法整理）

1. **分区**：视觉 / 听觉 / 触觉 / 平衡 四个感觉区 + 前额叶 + 运动区。
2. **输入编码**：每个像素有具体位置，分成 R/G/B 三个最基础的通道；
   每个通道用**温度计编码 N 档**，配**相反神经元（正、反一对）**——每一对**恰好亮一个**：
   亮到第 5 档时 5 个"正"细胞亮；纯黑时"反"细胞全亮（"什么都没有"也是一个读数）。
   → 输入层永远恰好一半活跃。
3. **立体与就近**：每个神经元有三维位置；出生连线**只能连更靠近自己的**（按 (y,z) 图像平面算距离，
   **层与层之间的 x 差不参与**，否则图像的"行"会被抹掉）。
4. **一层层往前送**：每个区有多层；**每一层都往前额叶方向送**（不是只有最后一层），
   路上每隔一小段放一级中继神经元，每级只接上一层就近的一小片；越靠近前额叶数量越多。
5. **前额叶 = 汇聚端**：不是传统网络，就是各条链的落点；内部暂不互连（等后天可塑连接）。
6. **返回通路（逆神经网络）**：前额叶 → 返回中继 → **按位置送回原来那一层**，是去程的反向；
   返回通路要**很多前额叶神经元同时活跃**才打得开（靠抑制细胞 + 阈值一起构成门槛），
   否则信号会在 a→b→c→d→a 之间自己转个不停。**返回中继不能落回第 1 层**（那是外界直接驱动的传感器，
   落回去会形成正反馈、整条链锁死在 1.0）。
7. **运动区**：肌肉数 × 力度档数（**不含抑制、不含中继**），不需要相反神经元；
   亮的力度神经元越多、出力越大。运动区有抑制神经元压住行动（它们的输入留给后天可塑连接）。
8. **门控**：不是"运动相关神经元亮了就发"——要看它是不是**主要被激活的那批**；
   无关神经元通过抑制细胞压住"往回发"的通路，只有**大量**运动相关神经元同时活跃才发得出去。
   去抑制（D）再由运动相关组自己打开。

## 二、实测验证过的结构规矩（改动前必读）

| # | 规矩 | 依据（实测） |
|---|---|---|
| 1 | 就近只看 (y,z)，层间 x 差不参与 | 用三维距离时每层只看到上一层最靠边一排，图像行信息全丢 |
| 2 | **深层感受野 ≤ 上一层的约 1/8** | 感受野≈整层时差别被平均掉：视觉第3层可分 0/12；1/4 → 2/12；**1/8 → 12/12** |
| 3 | 不能窄到"只读一条通道" | 那样每个神经元失去对照：第2层 11/12 → 1/12 |
| 4 | 门槛/带宽按**每个神经元自己拿到的信号**定 | 固定常数会在"整层死"和"整层饱和"之间来回跳 |
| 5 | **中转站与前额叶那一层要更松**（门槛 ≈ 0.30×中位驱动） | 这一条让"送到前额叶"从 7/48 变 48/48 |
| 6 | 回程只当调制（边数 ≤ 前向一半） | 回程占到入边 22/30 时前向被压死 |
| 7 | 整体阈值调控**只许微调**（增益是相对量，±0.05） | 放到 ±0.5 它会顶到上限、把所有门槛乘 1.5 倍，深层必死 |
| 8 | 各层必须落在分级区间 | 饱和（恒 1.0）传不出变化；死（恒 0）什么都没传 |
| 9 | 门槛的固定下限（如 0.02）必须去掉 | 它让下降链每过一级固定损失，力度低端被压缩 |

## 三、现在的实测结果

模型规模：10×10 像素、每像素 RGB、10 档、正反一对 → 视觉 6000 格输入；
听觉 20 / 触觉 40 / 平衡 6；共 **40,701 神经元、762,471 条连接**（先天全固定，可塑 0 条）。

**逐通道验收**（每条通道各动**最小一档**）：

| 区 | 通道数 | 第2层 | 第3层 | 第4层 | 送到前额叶 | 图案相似度 |
|---|---|---|---|---|---|---|
| 视觉 | 300（抽 30） | 30/30 | 30/30 | 30/30 | 27/30 | 0.02 |
| 听觉 | 20 | 20/20 | 20/20 | 20/20 | 20/20 | 0.28 |
| 触觉 | 40 | 40/40 | 40/40 | 40/40 | 40/40 | −0.02 |
| 平衡 | 6 | 6/6 | 6/6 | 6/6 | 6/6 | 0.14 |

**判据（重要）**：网络是确定的、无噪声——**只要输入有一个神经元变了、后面活动跟着变，就是能区分**。
所以用"该层活动差 > 1e-4"，**不要**用"差值必须 > 0.1"（那是在要求"变化大"，会严重低估模型）。

**运动力度**（点亮前额叶运动相关组的个数 → 出力档位，满档 10）：

```
亮 1 → 0 档   亮 2 → 1 档   亮 3 → 2 档   亮 5 → 6 档
亮 7 → 9 档   亮 8 → 10 档  亮 10 → 10 档       （单调、分级；亮 1~2 个时门控压着不出力）
```

**后天可塑连接**（`plastic.py` / `plastic2.py`，默认关闭）：

- 只有**刚刚变化**的神经元参与：`上一帧亮、这一帧灭` ↔ `这一帧刚亮`，以及 `同时刚亮` 的互相加强；
  **一直亮着的（如输入层）和一直灭的一条边都不产生**（否则常亮神经元会跟所有东西连上、把网络卡死）
- 增量 `Δw = η·a_i·a_j/(1+w/w_ref)^pow`：**无上限、越涨越难涨、不归一化**；"先亮的"那个神经元要用**上一帧**的活动
  （它这一帧已灭、当前活动是 0，用当前活动算增量会永远是 0 —— 这个 bug 修过一次）
- 每 200 拍所有可塑边整体降权 ×0.99（先天骨架不动）→ 实测：**常用 10.58 / 少用 0.56 / 从不用的消失**
- 新边可跨位置、跨层、跨区（出生连线不允许跨区，可塑连线不受限制）

**训练循环**（`train_loop.py`）：生成随机出生参数 → 同一套固定题库打分 → 选优 → 融合 → 再生成。
实测：第 1 代最高 0.933 → 第 3 代出现 **1.000** 的模型（最优：感受野 11、层比 ≈1.78/1.78/1.67）。

## 四、还没做到的部分（如实记录）

1. **顺序学习（看完动画能自己往后演）**：连接确实在长（引擎里可塑边表可达 4~5 万条），但
   "喂第一帧之后内部图案自己走到第二帧、第三帧"**目前没有出现**——只在第 1 帧附近起伏。
   已排除"连接太弱"这一条（学习步长放大 12 倍、接触 150 遍，行为不变）。
   缺的是"让当前状态退下去、由下一帧接管"的那一环。
2. **前额叶像文字网络那样"思考"**（激活少数神经元代表当前想法）：可塑连接还没接到运行循环里长期学习。
3. **实时性**：目标规模 + 开启可塑连接时每步约 **52 毫秒**（20 毫秒一拍的要求尚未满足）；
   不开可塑连接时更快。
4. 抑制神经元目前只在**运动区**与**返回通路的门槛**上使用；感觉区内部没有常驻抑制。

## 六、跑起来

```powershell
cd code
python accept_all.py     # 总验收：四区逐通道表 + 运动力度表 + 可塑自测（几分钟）
python tiny_accept.py    # 小模型（2×2 像素）逐通道验收，几秒钟
python test_force.py     # 运动力度分档
python test_plastic2.py  # 可塑连接规则（常用/少用/常亮不参与）
python train_loop.py     # 生成 → 测试 → 选优 → 融合
```

依赖：Python 3 + numpy（只用 numpy）。

## 一句话

**信号从各区一层层往前送、每一层都往额前叶送；前额叶是汇聚端、返回通路要"一大片同时活跃"才打得开；
运动区按力度分档出力，门控保证"不是随便亮几个就动手"。**
到目前：**四个区的每一条通道，最小的亮度/声音变化都能在每一层被区分出来，并基本都能送到前额叶**；
"顺序学习"和"前额叶思考"还没做到。
