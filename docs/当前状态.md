## 一、现在跑得怎么样（目标规模：10×10 像素、10 档、40,733 神经元、762,503 连接）

命令：`python accept3.py`

```
区      抽样    各层变化传导           送到前额叶   图案相似度
视觉     30   30/30  30/30  30/30      21~28/30    0.01~0.02
听觉     20   20/20  20/20  20/20      11/20       0.23     ← 唯一偏弱，支线 A 在修
触觉     40   40/40  40/40  40/40      40/40      -0.02
平衡      6     6/6    6/6    6/6        6/6       0.20
```

判据（务必用这个，不要用"差值必须 > 0.1"那套）：
- **变化传下去了吗** → 该层最大差 > 1e-4。网络是确定无噪声的，**变了就是能区分**，
  不要因为"找不到某个变化很大的特征神经元"就判它区分不了（这是我走过的大弯路）。
- **前额叶分得开吗** → 不同通道的响应图案两两相似度要低。
- 用"最大差 > 0.1"会严重低估模型能力。

## 二、已经验证成立的结构规矩（改动前先读这里）

1. **输入编码**：每通道温度计（N 档）+ 正反一对；每对恰好亮一个；纯黑时反细胞全亮。
2. **就近连线**：出生连接只能连更靠近自己的（(y,z) 平面距离，**层与层之间的 x 差不参与**）。
3. **深层感受野只能覆盖上一层的约 1/8**：宽了（1/4、2/3 整层）层内差别被平均掉，细微变化消失；
   窄到"只读一条通道"（k=2）也不行（第2层从 11/12 掉到 1/12）。区间在"**主 + 对照**"。
4. **门槛与带宽按"每个神经元自己拿到的信号"定**（`calib.py`）：
   - 门槛 = 0.7 × 它驱动的中位数（区内各层）
   - 带宽 = 2 × 驱动的起伏 + 0.15 × 中位（区内各层）
   - **中转站与前额叶那一层要更松**：门槛 0.30 × 中位（这一条让"送到前额叶"从 7/48 变 48/48）
   - 细胞少的组（最小的感觉区）起伏不可靠 → 带宽按 0.8 × 中位
   - 标定跑两遍（第二遍在门槛都设好的稳定状态下复测）
5. **回程只当调制**：回程的边数不超过该神经元前向入边的一半；**回程不能落回第 1 层**
   （第 1 层是外界直接驱动的传感器；落回去会形成正反馈，整条链锁死在 1.0）。
6. **整体阈值调控只许微调**：增益是相对量（门槛 ×(1+gain)），范围 ±0.05。
   放到 ±0.5 它会顶到上限、把所有门槛乘 1.5 倍，深层必死。
7. **各层必须落在分级区间**：饱和（恒 1.0）的层传不出变化，死（恒 0）的层什么都没传。

## 三、操作纪律（这一路最坑的三件事）

1. **补丁一律写成文件再执行**；**绝不用 `python -c "..."` 内联命令**——PowerShell 的引号
   弄坏过七八次，静默失败，害我拿着没改过的代码推了好几轮结论。
2. **改完必须验证"改动是否真的生效"**（打印实际写进去的值），再谈效果。
3. **先量数、再动手**：每次"深层死了/变化传不下去"的案子，都是打印数值（驱动、门槛、gain、
   入边来源）当场破的；先调参数的那些轮全部白费。
