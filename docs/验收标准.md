# 验收标准

## 一、核心判据（已按用户指正修正）

**"能区分"不等于"变化很大"。** 网络是确定的、没有噪声：**只要输入有一个神经元变了，
后面的活动必然跟着变，变了就是能区分。**

| 问什么 | 怎么量 | 通过线 |
|---|---|---|
| ① 变化传下去了吗 | 该层所有神经元里活动差的最大值 | **> 1e-4** |
| ② 前额叶分得开吗 | 不同通道响应图案两两相似度（余弦） | 越低越好（< 0.3 算分得开） |

**不要用"必须有某个神经元差 > 0.1"这种尺子**——那是在要求"变化大"，不是"能区分"，
会严重低估模型（我走过的大弯路，用户一句话点破）。

## 三、结构规矩（改动前必读，全部经实测确认）

1. 输入：每通道温度计（N 档）+ 正反一对；每对恰好亮一个；纯黑时反细胞全亮。
2. 出生连线只连更靠近自己的（(y,z) 平面距离，**层间 x 差不参与**）。
3. **深层感受野 ≤ 上一层的约 1/8**；窄到"只读一条通道"也不行 → 取"主 + 对照"。
4. 门槛/带宽按**每个神经元自己拿到的信号**定；**中转站与前额叶那一层要更松**（门槛 0.30×中位）。
5. 回程只当调制（边数 ≤ 前向一半）；**回程不能落回第 1 层**（会造成正反馈锁死）。
6. 整体阈值调控只许微调（增益是相对量 ±0.05）；放大到 ±0.5 会顶到上限、把深层压死。
7. 各层必须落在分级区间：饱和（恒 1.0）传不出变化，死（恒 0）什么都没传。

## 四、运动与可塑

- **运动力度分档**：亮的运动相关神经元个数 → 出力档位，必须单调、能分中间档（不是 0 或满）。
- **可塑连接**（当前应全为 0 条）：时序赫布增长（无上限、越涨越难涨、不归一化）
  + 周期整体降权（只降"可改变"的连接，先天骨架不动）+ 允许长出跨区新连接。
- **实时性**：20 毫秒一拍内跑完。

## 五、操作纪律（这一路最坑的三件事）

1. 补丁一律写成文件再执行；**绝不用 `python -c "..."` 内联命令**。
2. 改完必须验证"改动真的生效了"（打印实际值），再谈效果。
3. **先量数、再动手**；每次"深层死了"的案子都是打印数值当场破的。
