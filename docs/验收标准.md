# 验收标准

## 一、核心判据（已按用户指正修正）

**"能区分"不等于"变化很大"。** 网络是确定的、没有噪声：**只要输入有一个神经元变了，
后面的活动必然跟着变，变了就是能区分。**

| 问什么 | 怎么量 | 通过线 |
|---|---|---|
| ① 变化传下去了吗 | 该层所有神经元里活动差的最大值 | **> 1e-4** |
| ② 前额叶分得开吗 | 不同通道响应图案两两相似度（余弦） | 越低越好（< 0.3 算分得开） |

**不要用"必须有某个神经元差 > 0.1"这种尺子**——那是在要求"变化大"，不是"能区分"，
会严重低估模型（我走过的大弯路，用户一句话点破）。

## 二、逐通道表（每个区、每条通道各动最小一档）


## 三、结构规矩（改动前必读，全部经实测确认）

1. 输入：每通道温度计（N 档）+ 正反一对；每对恰好亮一个；纯黑时反细胞全亮。
2. 出生连线只连更靠近自己的（(y,z) 平面距离，**层间 x 差不参与**）。
3. **深层感受野 ≤ 上一层的约 1/8**；窄到"只读一条通道"也不行 → 取"主 + 对照"。
4. 门槛/带宽按**每个神经元自己拿到的信号**定；**中转站与前额叶那一层要更松**（门槛 0.30×中位）。
5. 回程只当调制（边数 ≤ 前向一半，实测 0.50/0.35）；**回程不能落回第 1 层**（会造成正反馈锁死）；
   **回程门槛必须 ≤ 入边权重和**（写 2.0× 时 act≤1 永远打不开），抑制只压第一级；
   回程要看"随机铺开"的前额叶（只取最近会变成看局部小簇，20% 就打开）。
6. 整体阈值调控只许微调（增益是相对量 ±0.05）；放大到 ±0.5 会顶到上限、把深层压死。
7. 各层必须落在分级区间：饱和（恒 1.0）传不出变化，死（恒 0）什么都没传。
8. **链上每级一对一（专用线）**：一个中继只接一个上游神经元，只有前额叶做多输入汇聚；
   多级"就近 k 个"混合会把细节磨掉（ρ 0.44→0.11→0.0），改一对一后四区送额叶全部 100%。
9. **增神经元：L2–L5 都能加，逐层试、按目标区选层**。链的区内链是 L1 传感器 + L2–L5；
   5% 父单元 × 2 子单元 × 2 输入，子单元局部重连下一层 + 各配专用线送前额叶，
   并给这一层的前额叶组 +1 个接收端（前额叶是落点，不跟 L2–L5 并列）。
   中等规模（触觉最差时）：L2 0.566、L3 0.543、L4 0.532、L5 0.511——越深越好，L5 最优。
   加完**不重标定整网**（重标会把提升洗掉：L3 0.192→0.178，重标后回到 0.203）。
10. **常亮/静默筛选只对最新网络的区做**（默认视觉）：听觉/触觉/平衡的专用网络还没做出来（旧网络），
    参考输入下大量静默细胞，按"静默就删"会连带把它们的额叶组打塌；这三个区先只加不删。
    只筛"平均 > 0.5、跨输入 std ≈ 0"的来源；常灭的走删除。参考输入不足时不要按"常灭"砍额叶入边。
11. **结构改动的验收**：定点改动只看目标区变好（>0.01）、**每一层额叶组**不显著变差（>0.02），
    否则回滚。改动后**不重标定整网**（实测重标会把增益洗掉、还会让某组塌：L3 0.192→0.178，重标后 0.203；
    触觉 L4 0.47→0.86），只给新神经元/新接收端设门槛。

## 四、运动、可塑与结构

- **运动力度分档**：亮的运动相关神经元个数 → 出力档位，必须单调、能分中间档（不是 0 或满）。
- **可塑连接**（当前应全为 0 条）：时序赫布增长（无上限、越涨越难涨、不归一化）
  + 周期整体降权（只降"可改变"的连接，先天骨架不动）+ 允许长出跨区新连接。
- **结构可塑性**（`structure.py`）：增/删神经元、常亮不送额叶；每次改动后重新标定，
  前额叶四区相似度复测，**变差回滚**。
- **实时性**：20 毫秒一拍内跑完；5 层静态目标规模实测 **8.08 毫秒/步**（在 `run.py` 里量）。

## 五、操作纪律（这一路最坑的三件事）

1. 补丁一律写成文件再执行；**绝不用 `python -c "..."` 内联命令**。
2. 改完必须验证"改动真的生效了"（打印实际值），再谈效果。
3. **先量数、再动手**；每次"深层死了"的案子都是打印数值当场破的。
